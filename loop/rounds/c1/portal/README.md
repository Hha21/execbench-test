# Control c1: portal repeatability

`c1-control-r6.json` has exactly the same code as `r6-s-ldef-nc-disp` (portal 0.609882 on 7 October, #62049).
Its score now tells us how much the portal moves for identical code between days or machines. r8/r9 (submitted
together a day later) were 4.2% slower than r6 at medium sizes with near-identical medium-size code.
